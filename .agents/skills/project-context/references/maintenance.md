# ctx-* skill 手动维护规则

当用户明确要求手动维护前端项目的持久化上下文，或明确维护某个 `ctx-*` skill 及其内部资源时，按本流程处理。手动维护包括记录、沉淀、补充、完善、修正、更新，以及创建、删除、拆分、合并、重命名、移动或整理。

## 范围与边界

本流程仅编排直接位于 `.agents/skills/` 下的 `ctx-*` skill 及其内部资源的维护。

## 处理步骤

1. 读取用户指定的代码、diff、说明及相关 `ctx-*` skill 和内部资源；按知识边界拆分候选内容。
2. 用户明确要求删除、拆分、合并、重命名、移动或整理 skill 或内部资源时，读取 `reorganization.md`，先输出计划并等待确认。
3. 对每项非结构调整的候选内容，读取并执行 `selection.md` 的选择结果。

## 维护结果

以 `project-context：` 开头汇总本次维护结果，使用户能够识别该结果由本 skill 产生。向用户列出已更新或创建的 `ctx-*` skill、内部 resource 和项目基础上下文，并为每项给出证据。另列出待确认、跳过和已检查无需更新的内容；结构调整尚未确认时，说明已输出的计划及未执行的原因。
