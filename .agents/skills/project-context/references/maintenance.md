# ctx-* skill 维护流程

本文件是所有 `ctx-*` skill 及其内部资源变更的唯一入口。它接收 [初始化规则](./initialization.md) 生成的候选内容，或根据用户的维护请求生成候选内容，并统一完成选择、执行和结果输出。

## 范围

只维护直接位于 `.agents/skills/` 下的 `ctx-*` skill 及其内部资源，包括尚未迁移的旧版 `ctx-<分类>-<主题>`；规范入口 `ctx-project-baseline` 不属于旧结构。不修改 `project-context`、非 `ctx-*` skill、项目代码、配置、Git 历史或 `docs/`。

## 确定维护范围和候选内容

从以下可用来源确定本次维护范围：

- 当前请求和当前可见会话中的相关说明；
- 用户指定的 commit、git diff、代码和当前工作树；
- `initialization.md` 提供的初始候选内容；
- 相关 `ctx-*` skill 及其明确引用的内部 resource。

不同会话中的说明只有在当前可见或由用户提供时才可作为证据。已提交和未提交修改都只是候选证据，不自动触发记录，也不自动扩大用户指定的范围。

按可独立证实的知识边界拆分候选内容。每项候选内容应包含用户意图、证据来源和可能相关的既有上下文；不要根据页面清单直接生成顶层 skill 候选。

## 选择和执行

1. 将每项候选内容交给 [选择规则](./selection.md)，取得最终状态、固定分类、目标 skill、目标文件和所需按需规则。
2. 写入前区分普通内容变更和结构调整。需要删除、拆分、合并、重命名、移动或整理已有 skill 或内部 resource 时，先读取 [结构调整规则](./structural-changes.md)。取得确认前，不写入该调整涉及的文件，包括承接迁移内容的新文件。
3. 对可执行的“新增”“更新”或普通内容“删除”结果，只修改选择结果指定的文件及其关联入口。首次创建分类级 skill 时，按 [结构规则](./template.md) 创建最小 `SKILL.md`，不预建没有保留内容的分类。普通旧内容更新沿用选择规则确定的位置，不扩张其他主题。
4. 按 `template.md` 执行关联的路由、架构层级和 `ctx-other` 触发条件更新，并将这些关联文件计入本次变更范围。内容应进入 reference 时，再读取 [内部 reference 规则](./internal-references.md) 确定写入方式。
5. 完成文件变更后，执行下文的“完成检查”，再汇总维护结果。

“保持不变”和“跳过”不修改文件；“待确认”在获得足够证据或用户决定前不执行。保留工作树中的用户已有改动，只修改本次选择结果直接涉及的内容。

用户只要求分析或规划时，执行相同的范围识别和选择，但不创建、修改、移动、重命名或删除文件。

## 完成检查

所有实际变更都执行以下检查，包括普通更新和结构调整。检查范围限于本次修改的 skill、内部 resource 及受影响的引用，不自动扩展为全量审计。

1. 对照选择结果和执行前的工作树，检查最终 diff，包括新建的未跟踪文件。确认未覆盖用户已有改动，且修改范围与请求或已确认的结构调整计划一致。
2. 检查涉及的 `SKILL.md`：frontmatter 可解析，`name`、`description` 非空，名称与目录一致。新增入口使用规范名称；原地更新的旧 skill 按 [分类规则](./taxonomy.md) 检查兼容性，不因检查自动迁移。
3. 按 [结构规则](./template.md) 核对每个涉及的 reference 是否有可识别的直接路由、必要的组合读取条件及有效路径。同时检查受影响的入口关系；涉及 `ctx-other` 时核对 description 的主题覆盖。
4. 核对修改的结论与证据是否对应，共同约束与相关 reference 是否冲突，是否产生重复权威记录。涉及用户明确规则或架构状态时，分别按选择规则和结构规则核对。
5. 检查失败时，修正本次修改引入的问题后重查。超出授权范围、证据不足或需要新的结构调整确认时，保留未解决项并报告，不宣称相关项已完成。不得用清理用户已有改动的方式通过检查。

只分析或规划时，仅核对决策和计划，并确认未写入文件；不把计划中的路径当作已创建文件验证。

## 维护结果

以 `project-context：` 开头汇总结果。列出实际新增、更新或删除的 skill、内部 resource、语义路由和项目基础上下文，并为每项给出证据。简述完成检查的结果和未解决项。另列出待确认、跳过和保持不变的内容；结构调整尚未确认时，说明已输出的计划及未执行原因。
